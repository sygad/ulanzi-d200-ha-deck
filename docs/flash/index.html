Put the software on the board

This is the one step of the wireless route that needs a computer, and it is done once. Any computer will do: nothing is installed on it and nothing is typed. When it is finished the board never needs that computer again.

  1. Open this page in Chrome or Edge, on a computer. Safari, Firefox and phones cannot talk to a board over USB, so the button below will say so.
  2. Plug a USB cable from the computer into the socket on the board marked COM. Leave the socket marked USB empty for now. It has to be a cable that carries data; some cables only charge.
  3. Press Install. The browser lists what is plugged in: pick the board and press Connect. Then follow what it says and leave it alone until it reports that it has finished.
  4. Unplug the board and go back to the guide.
